# 🎓 Campus Exchange Hub

A full-stack MERN web application that allows students to buy and sell used items within their college campus. The platform provides a simple and secure marketplace where students can list products, browse available items, save favorites, and contact sellers directly.

---

## 🚀 Features

### 👤 User Authentication

- User Signup
- User Login
- Logout
- Protected Routes

### 🛍 Product Management

- Add Product
- Edit Product
- Delete Product
- View Product Details
- Upload up to 5 Product Images
- Mark Product as Sold

### ❤️ Wishlist

- Add Product to Wishlist
- Remove Product from Wishlist
- Red Heart for Wishlisted Products
- Wishlist Page

### 🔍 Search & Filter

- Search Products by Name
- Filter Products by Category

### 📱 Seller Contact

- Contact Seller using Phone Number

### 🎨 User Interface

- Responsive Design
- Toast Notifications
- Attractive Home Page
- Product Cards
- Default Image Support

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/Gaganbatth/campus-exchange-hub.git
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```
MONGO_URI=Your_MongoDB_Connection_String

PORT=5000
```
